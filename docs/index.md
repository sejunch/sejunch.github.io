## 한랭 — 한글 프로그래밍 언어

한국어로 읽히는 교육용 프로그래밍 언어. 조사가 함수 인자의 이름표가 된다.
인터프리터가 아니라 **x86-64 네이티브로 컴파일**된다.

```
학생 이란 묶음 {
    이름은 문자.
    점수는 정수.
}

반은 []이다.
반에 (새 학생)을 넣다.
(반의 1번째)의 이름은 "세준"이다.
(반의 1번째)의 점수는 95이다.

만약 (((반의 1번째)의 점수) >= 90) 라면 {
    ((반의 1번째)의 이름)을 끝"(이)가 " 말하다.
    "1등!"이라고 말하다.
}
```

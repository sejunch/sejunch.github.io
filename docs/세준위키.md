# 세준위키

!!! abstract "개요"
    지금 보고 있는 이 위키. [세준](세준.md)이 만든 것들을 정리해 두는 곳이다.
    마크다운으로 문서를 쓰면 GitHub Actions가 정적 사이트로 빌드해
    GitHub Pages에 올린다.[^repo]

[^repo]: [github.com/sejunch/sejunch.github.io](https://github.com/sejunch/sejunch.github.io)

## 1. 개요

만든 것이 하나둘 늘면서 "이거 어디에 정리해 두지" 하는 문제가 생겼다.
저장소 README는 그 프로젝트 안에서만 말이 되고, 프로젝트끼리 엮이지 않는다.

그래서 **문서끼리 링크로 이어지는 위키** 형태를 골랐다.
프로젝트 문서에서 사람 문서로, 사람 문서에서 다른 프로젝트로,
[한랭](한랭.md)에서 [한글 프로그래밍 언어](한글-프로그래밍-언어.md) 같은
배경 문서로 넘어갈 수 있다.

## 2. 어떻게 만들었나

| 분류 | 쓴 것 |
|------|-------|
| 생성기 | MkDocs + Material 테마 |
| 문서 | 마크다운 |
| 호스팅 | GitHub Pages |
| 배포 | GitHub Actions (`main` 에 push 하면 자동) |

서버가 없다. 마크다운을 미리 HTML로 구워서 올려 두는 **정적 사이트**라
돈이 들지 않고 관리할 것도 없다.

### 2.1. 한글 검색

Material 테마의 기본 검색은 한글에서 잘 안 걸린다.
띄어쓰기 단위로만 낱말을 끊는데, 한국어는 `조사를`, `조사가`, `조사는` 처럼
조사가 붙어 다니기 때문이다. `조사` 를 검색해도 `조사를` 이 안 잡힌다.

검색 인덱스를 만들 때 쓰는 구분자를 조사까지 끊도록 손봐서 해결했다.

```yaml
plugins:
  - search:
      separator: '[\s​\-,:!=\[\]()"`/]+|\.(?!\d)|&[lg]t;'
```

### 2.2. 문서 모양

나무위키를 참고했다. 문서마다 이런 것들이 있다.

- 맨 위에 **개요 상자** — 이 문서가 뭘 다루는지 한 문단
- 번호 붙은 **목차** (오른쪽에 따라다닌다)
- **각주** — 출처나 곁가지 설명
- **분류** — 문서 아래에 붙고 [분류](분류.md) 문서에 모인다
- 맨 아래 **관련 문서**

## 3. 구조

```
docs/
├── index.md                    대문
├── 세준.md                      사람
├── 한랭.md                      만든 것
├── 앰타.md
├── 세준위키.md                   ← 이 문서
├── 한글-프로그래밍-언어.md         알아본 것
└── 분류.md
```

문서를 새로 만들려면 `docs/` 에 마크다운 파일 하나 만들고
`mkdocs.yml` 의 `nav` 에 한 줄 추가하면 된다.

## 4. 앞으로

- 프로젝트가 늘면 문서도 늘린다
- 만들다 막힌 것과 푼 방법을 따로 정리할 생각이다

# 한랭 (hanlang)

한국어로 읽히는 교육용 프로그래밍 언어. 확장자는 `.han`.

[GitHub 저장소](https://github.com/sejunch/hanlang){ .md-button .md-button--primary }

---

## 뭐가 다른가

### 조사가 인자 이름표가 된다

함수를 정의할 때 쓴 조사가 그대로 호출 규약이 된다.

```
가와 나를 더하다 란 {
    가 + 나를 돌려주다.
}

(3과 4를 더하다)를 말하다.       // 7
```

스위프트가 `foo(from:to:)` 처럼 억지로 만든 인자 라벨을,
한국어는 조사로 이미 갖고 있다. 문법이 공짜로 해준다.

### 인터프리터가 아니다

C++로 짠 컴파일러 한 파일이 x86-64 어셈블리를 뱉고 gcc로 링크한다.
별도 실행 환경 없이 리눅스 실행 파일이 그냥 나온다.

```bash
./hanc 프로그램.han -o 프로그램
./프로그램
```

### 에러 메시지가 핵심 기능

```
[오류] 3행: '나이' 는 정수 변수인데 소수를 넣으려 함. 처음부터 소수로 쓰려면 0.0 처럼 만들기
  3 | 나이는 3.5이다.
    | ^^^^
```

한국어로, 소스 줄과 캐럿과 고치는 법까지 나온다.
함수가 타입마다 따로 만들어지기 때문에 몸통에서 에러가 날 수 있는데,
그럴 땐 **어느 호출 때문인지**도 같이 알려준다.

```
[오류] 1행: '*' 는 숫자끼리만 됨
  1 | 수를 두배로 란 { (수 * 2)를 돌려주다. }
    |                      ^
  '두배로' 를 3행에서 부름 (인자: 문자)
```

### 표준 라이브러리가 이 언어로 짜여 있다

8개 파일 79개 함수 전부 `.han` 이다. 열어서 읽으면 그대로 공부가 된다.
`lib/정렬.han` 에는 선택·삽입·퀵·병합 정렬이 나란히 들어 있다.

## 할 수 있는 것

| | |
|---|---|
| 타입 | 정수 · 소수 · 문자 · 목록 · 격자(2차원) · 묶음(구조체) |
| 함수 | 타입을 안 적어도 되고, **인자 타입 조합마다 컴파일러가 따로 만든다** |
| 반복 | `10번 반복하다`, `(조건) 인 동안`, `멈추다` / `계속하다` |
| 연산 | 몫 `~/`, 나머지 `%`, 비트 `& \| ^ ~ << >>` (전부 C와 같은 우선순위) |
| 문자 | 한글도 한 글자로 센다. `("가"의 코드)` = 44032 |
| 모듈 | `"정렬.han"을 불러오다.` — 순환·중복 자동 차단 |
| 안전 | 범위 밖 접근, 0 나누기, 시프트 범위 밖 전부 실행 중에 잡는다 |

같은 함수를 여러 타입에 쓸 수 있다.

```
가와 나를 더하다 란 { 가 + 나를 돌려주다. }

(3과 4를 더하다)를 말하다.          // 7
(1.5와 2.25를 더하다)를 말하다.      // 3.75
("가"와 "나"를 더하다)를 말하다.     // 가나   같은 함수다
```

## 써보기

```bash
git clone https://github.com/sejunch/hanlang
cd hanlang
make
./han examples/demo.han
```

설치는 `sudo make install`. 테스트는 `make test` (60개).

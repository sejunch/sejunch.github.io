# 세준

!!! abstract "개요"
    프로그래밍을 배우고 있는 고등학생. 언어와 컴파일러 쪽에 관심이 있다.
    만든 것 중 가장 큰 것은 한국어 프로그래밍 언어 **[한랭](한랭.md)** 이다.

## 1. 개요

2026년 기준 고등학교 1학년. C++와 알고리즘을 공부하고 있다.

컴퓨터가 사람 말을 어떻게 알아듣게 만들 수 있는지에 관심이 많아서,
직접 프로그래밍 언어와 컴파일러를 만들고 있다.

## 2. 만든 것

### 2.1. 한랭

자세한 내용은 **[한랭](한랭.md)** 문서 참고.

한국어로 읽히는 프로그래밍 언어. 조사를 문법 요소로 쓰는 것이 특징이다.
C++로 컴파일러를 직접 작성했고, 인터프리터가 아니라 x86-64 어셈블리를 생성해
gcc로 링크하기 때문에 네이티브 실행 파일이 나온다.

```
가와 나를 더하다 란 {
    가 + 나를 돌려주다.
}

(3과 4를 더하다)를 말하다.       // 7
```

2026년 7월 공개. MIT 라이선스.

### 2.2. 앰타

자세한 내용은 **[앰타](앰타.md)** 문서 참고.

AI 캐릭터를 만들어 공개하고 다른 사람이 만든 캐릭터와 대화하는 웹 서비스.
Next.js와 MongoDB, Google Gemini API로 만들었다. 로그인, 데이터베이스,
외부 AI API, 권한 관리를 한 번에 다뤄 본 작업이다.

[emta-ai.vercel.app](https://emta-ai.vercel.app) 에서 돌아가고 있다. 2026년 5~6월.

### 2.3. 증강 체스

자세한 내용은 **[증강 체스](증강체스.md)** 문서 참고.

변형 체스 웹 게임. 기물의 움직임을 **Chessembly**라는 언어로 정의하고,
게임 도중 카드를 뽑아 기물을 바꾼다. 보드 크기도 바꿀 수 있다.
체스 라이브러리 없이 엔진을 직접 썼다.

한랭이 사람이 읽는 언어라면 이쪽은 기물 움직임을 적는 작은 언어라,
결국 같은 종류의 일이다.

**미완성으로 접었다.** 흥미가 떨어진 것도 있지만, 붙어 있는 기능이 너무 많아져
한 곳을 건드리면 다른 곳이 흔들리는 상태가 된 것이 컸다.

### 2.4. 세준위키

자세한 내용은 **[세준위키](세준위키.md)** 문서 참고.

마크다운으로 쓰면 GitHub Actions가 정적 사이트로 구워 GitHub Pages에 올린다.

### 2.5. 그 외

자세한 내용은 **[그 외 잡다한 것들](잡다한것들.md)** 문서 참고.

진자 강화학습 시뮬레이터(PPO를 numpy로 직접 구현), 디스코드 봇,

## 4. 작업 방식

**코드는 전부 [Claude](https://claude.ai)와 함께 쓴다.**

대신 **무엇을 만들지와 어떻게 생겨야 하는지는 직접 정한다.**
특히 [한랭](한랭.md)처럼 언어를 만드는 일은 문법 하나하나가 결정이라,
그 결정을 남에게 맡기면 내 언어가 아니게 된다.

실제로 한랭의 문법은 대부분 이렇게 정해졌다.

- 몫 연산자를 `~/` 로 한 것 — `//` 는 주석과 부딪혀 못 쓰니
  기호 후보를 놓고 골랐다.
- 2차원 배열을 `3행 4열` 로 읽게 한 것.
- 출력 끝맺음 `끝"..."` — 한 줄에 여러 값을 찍는 방법으로 여러 안이 나왔는데
  전부 마음에 안 들어서, `\n` 은 한글이 아니니 조사와 서술어 사이에
  옵션을 넣자고 직접 제안한 것이 지금 문법이 됐다.

배열 인덱스를 1부터 세기로 한 것, 언어 이름과 확장자, 라이선스 같은 것도
마찬가지다.

만드는 속도가 훨씬 빨라진다는 게 가장 큰 이점이다.
컴파일러 하나를 며칠 만에 굴러가는 상태까지 끌고 갈 수 있으면,
그만큼 더 많이 시도해 보고 더 많이 틀려 볼 수 있다.

## 7. 여담

- 컴파일러를 만들면서 가장 오래 붙잡은 건 파서가 아니라 **조사를 떼어내는 부분**이었다.
  `가와 나를 더하다` 에서 매개변수 `가` 와 조사 `가` 가 겹치는 문제 때문이다.
  자세한 내용은 [한랭](한랭.md#43-조사-분리기) 문서에 있다.
- 한랭의 표준 라이브러리는 한랭 자체로 작성되어 있다. 언어가 스스로를 지탱할 만큼
  쓸모 있는지 확인하려는 의도였다.

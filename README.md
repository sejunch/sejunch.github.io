# 세준위키

https://sejunch.github.io 소스.

## 고치는 법 — 둘 중 편한 쪽

### 1. 브라우저에서 (제일 쉬움)

문서 오른쪽 위 **연필 버튼**을 누르면 GitHub 편집기가 열린다.
고치고 아래 **Commit changes** 누르면 끝. 1~2분 뒤 사이트에 반영된다.
휴대폰에서도 된다.

### 2. 여기서

```bash
./wiki 보기           # 미리보기 (http://127.0.0.1:8000)
./wiki 새글 문서이름   # 새 문서 + 메뉴 등록까지
./wiki 올리기         # 커밋하고 push
./wiki 확인           # 링크 깨진 곳 찾기
```

`./wiki 보기` 를 켜 두면 마크다운을 고치는 순간 브라우저가 알아서 새로고침된다.
처음 한 번은 알아서 준비(venv + 설치)하니 그냥 실행하면 된다.

## 문서 쓰는 법

```markdown
---
tags:
  - 만든 것          # 분류. 분류 문서에 자동으로 모인다
---

# 문서 이름

!!! abstract "개요"
    한 문단 요약.

## 1. 개요
## 2. 특징
## 3. 관련 문서
```

- 다른 문서로 링크: `[한랭](한랭.md)`
- 문서 안 특정 절로: `[한랭](한랭.md#4-만든-과정)`
- 각주: 본문에 `[^이름]`, 아래에 `[^이름]: 내용`
- 상자: `!!! abstract "개요"` / `!!! warning "만드는 중"` / `!!! note`

## 처음 설정

`./wiki` 가 알아서 한다. 직접 하려면:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```
